# kernoid apps

The **first-party apps** of [kernoid](https://kernoid.dev) – one sovereign core for mail, identity and files – licensed
under **MIT**.

> **Status: first prototype.** Signing in with an app password, mail (mailboxes, messages, reading, sending plain
> text) with end-to-end encryption (the key made here, unlocked with the recovery code; encrypted and signed whenever
> every recipient has a key), calendars (two weeks as a list of days; events made, changed, deleted and answered),
> contacts (search; made, changed, deleted; writing to one) and files (stores, directories, saving a file) on macOS,
> iOS, Linux, Android and Windows.
> Nothing to install yet. What the apps will be and how they are built is in [docs/plan.md](docs/plan.md).

## What they are

- **One Flutter app** for macOS, iOS, Linux, Android and Windows – the same functions on every one of them, with
  files in the system's file manager through a small native part per system.
- **Clients of open protocols only** – JMAP, WebDAV, CalDAV/CardDAV, OIDC – through kernoid's Rust SDK (MIT,
  `kernoid-client` and `kernoid-sync` from crates.io). They contain no code of the kernoid server, which stays
  AGPL-3.0-or-later like its terminal app.
- **End-to-end encryption without setting it up** – keys, finding and publishing them, encrypting – on
  `kernoid-e2e` (RFC 0006 of kernoid).
- **MIT**, so that they can be distributed through app stores as well – on phones and on desktops. Anyone may write
  their own apps against the same protocols.

## Build

[Flutter](https://docs.flutter.dev/get-started/install) 3.47.8 and [rustup](https://rustup.rs) – the Rust version and
targets come from `rust/rust-toolchain.toml`. Then `flutter run -d macos` (or `ios`, `linux`, `android`, `windows`);
the first build compiles the Rust side, later ones only what changed. Linux needs `libgtk-3-dev`.

| Path | Content |
|---|---|
| `lib/` | the app: `pages/` (login, mail, calendar, contacts, files, account), `app/` (theme in kernoid's colours, formats, saving), `l10n/` (English and German) |
| `rust/` | the Rust side: `src/api/` is what Dart calls, on kernoid's Rust SDK (`kernoid-client` and `kernoid-e2e`, MIT) |
| `lib/src/rust/`, `rust/src/frb_generated.rs` | generated by `flutter_rust_bridge_codegen generate` (2.13.0, with `cargo-expand`) – never edited |
| `rust_builder/` | the Flutter plugin that builds `rust/` with cargokit |
| `integration_test/` | the app against a real kernoid, see the file's head |

Checks, as CI runs them:

```sh
(cd rust && cargo fmt --check && cargo clippy --locked --all-targets && cargo test --locked && cargo deny check)
dart format --output=none --set-exit-if-changed lib test integration_test && flutter analyze && flutter test
scripts/check-age.py      # after changing rust/Cargo.lock: crates younger than two weeks
```
